## DATA

Nothing inside `raw/` or `processed/` is commited to git. This file documentswhere each dataset comes from and how to obtain it.

### wagenaar-2006 (real)
Paper: Wagenaar, D.A., Pine, J. & Potter, S.M. (2006). An extremely richrepertoire of bursting patterns during the development of cortical cultures.BMC Neuroscience, 7:11.

Source: https://potterlab.bme.gatech.edu

Terms: free for research; the paper must be cited in any publication.

Contents: 58 dissociated rat cortical cultures on 60-channel MEAs,963 half-hour spontaneous recordings, days in vitro 5-39.

Format: one file per recording, two columns: time_s channel.

Downloaded by: scripts/download_data.py into raw/wagenaar/.
